# Ecommerce Next.js

Ecommerce escalable construido con Next.js 14, TypeScript y Tailwind CSS.

## Características

- 🛒 Carrito de compras completo
- ❤️ Lista de deseos
- 🔐 Autenticación de usuarios
- 📱 Diseño responsive
- 🎨 UI moderna con Tailwind CSS
- ⚡ Optimizado con Next.js
- 🔍 Búsqueda en tiempo real

## Instalación

\`\`\`bash
npm install
npm run dev
\`\`\`

## Stack Tecnológico

- Next.js 14
- TypeScript
- Tailwind CSS
- React Context API
- Lucide Icons

## Estructura del Proyecto

- `/app` - Rutas y páginas de Next.js
- `/components` - Componentes reutilizables
- `/contexts` - Contextos globales (Auth, Cart, Wishlist)
- `/types` - Definiciones de TypeScript
- `/lib` - Utilidades y helpers

## Despliegue

\`\`\`bash
npm run build
npm start
\`\`\`
